六、注意事项

  1. sessionTarget 必须用 “isolated” - 避免阻塞主会话
  2. 首次使用需手动创建 memory 目录 - 否则索引会失败
  3. Google embedding 有免费额度 - 个人使用完全足够
  4. MEMORY.md 保持精简 - 日常细节留在日记，只提炼关键知识
